# WeatherCalendarApp
A Flutter/Dart weather app that doubles as a short-term calendar. Users can browse a 7 day weather forecast, view hourly weather details for each day, and schedule events at specific times. The app also supports recurring events, making it easy to track daily activities and plans.


This app has been built through android studios. When the app is running the UI is very simple and shows you a timeline of the week along with the overall weather and temperature for each respective day. When you select and click on any day it will open up with a scrollable horizontal wheel where you can view the weather and temp at different times throughout the day (must use touchscreen for scrolling horizontally will fix in future update.)  Below the horizontal wheel there is an add activity button that will let you create an activity and select a time for when you want it to be put into the calendar, there is also an option to repeat the activity daily. After adding an activity you can go to it on whichever day you scheduled it for to view it and you have the option to delete it. This app supports dark mode as well.
